=== Блокировка иностранного трафика ===

Установка
1. Отключите предыдущую версию плагина.
2. Установите архив spamblock-improved.zip через Плагины -> Добавить плагин.
3. Откройте Настройки -> Блокировка трафика.
4. На первом этапе выберите режим «Наблюдение».
5. Проверьте журнал, добавьте нужные IP и URL в белые списки.
6. После проверки включите режим «Блокировка».

Google и Яндекс
Поисковые роботы пропускаются только после двойной DNS-проверки:
обратное имя должно принадлежать разрешённому домену поисковика,
а прямое разрешение этого имени должно вернуть исходный IP.

Фильтр User-Agent
В настройках можно отдельно включить поиск ключевых слов в User-Agent, выбрать
режим наблюдения или блокировки и изменить список фрагментов. Фильтр по умолчанию
выключен. Подтверждённые роботы Google и Яндекса проверяются до этого фильтра.

Журнал
Плагин хранит не более 100 событий, но на странице можно компактно показывать
только последние 10, 20 или 50 записей.

Конфиденциальность
В журнале хранятся полные IP-адреса и только последние 100 событий. Учитывайте,
что IP может считаться персональными данными. GeoIP определяется через HTTPS
API ipwho.is, если страна не была получена другим интеграционным способом.

Примечание
Для крупных сайтов рекомендуется локальная GeoIP-база и постоянный object
cache (Redis/Memcached). Они не включены в архив и настраиваются отдельно.
